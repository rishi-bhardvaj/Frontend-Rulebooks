# Design Inspiration Sources

External references are research inputs, not templates. Use the source that matches the design problem.

| Source | Best use | What to inspect | Guardrail |
| --- | --- | --- | --- |
| Awwwards | Award-level websites, craft, interaction | composition, type, motion, transitions, creative direction | do not clone; award quality does not prove product fit |
| Brandfetch | Brand identity and brand asset context | logos, color systems, brand presentation, asset consistency | do not reuse protected assets without permission |
| Godly / Recent | Contemporary web direction | typography, composition, restrained art direction | avoid cargo-culting trends |
| SiteInspire | Broad web layout research | grids, hierarchy, content presentation | prefer patterns relevant to the product |
| CSS Design Awards | Frontend craft | implementation-aware interaction and visual quality | do not optimize for awards over usability |
| Mobbin / Page Flows | Proven product UX | real screens, states, onboarding, navigation, forms | treat captured UI as pattern evidence, not design authority |
| Behance | Design systems and case studies | art direction, process, identity, visual systems | distinguish concept work from shipped behavior |
| Dribbble | Exploratory visual ideas | components, type treatments, interaction concepts | never assume a shot is a production-ready flow |
| Land-book / Lapa Ninja / One Page Love | Landing-page structure | section order, CTA hierarchy, content density | match to real content and conversion goals |
| The FWA | Experimental interaction | motion, transitions, storytelling | use only when motion serves product intent |

## Suggested research mix

For a substantial new marketing or brand surface, combine at least one high-craft gallery (such as Awwwards), one broader layout source (such as SiteInspire), and one product/brand source appropriate to the feature (such as Brandfetch, Mobbin, or Page Flows).

For a product application screen, prioritize Mobbin/Page Flows and the existing design system; use Awwwards or The FWA only for interaction/craft inspiration when relevant.

For a brand-led page, prioritize the product's existing identity plus Brandfetch-style brand context, then use Awwwards/Godly/SiteInspire for composition and type.

Research should end in a visual thesis and explicit adaptation. Bookmarking references without turning them into product-specific decisions is not sufficient.
