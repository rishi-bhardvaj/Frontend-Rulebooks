# Frontend Testing Checklist

- [ ] Relevant unit/component tests were run.
- [ ] Relevant integration tests were run.
- [ ] Critical E2E/browser flow was exercised where applicable.
- [ ] Success path passes.
- [ ] Loading/empty/error states were checked.
- [ ] Validation and duplicate submission behavior were checked.
- [ ] Auth/permission-denied behavior was checked where relevant.
- [ ] Responsive behavior was checked.
- [ ] Keyboard/accessibility behavior was checked.
- [ ] Real API behavior was verified when integration work is involved.
- [ ] Mocked tests were not mistaken for production integration evidence.
