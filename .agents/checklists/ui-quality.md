# UI Quality Checklist

- [ ] Screen belongs visually to the existing product.
- [ ] Typography, spacing, color, radius, shadows, and icons follow established conventions.
- [ ] No gratuitous AI-template aesthetics were introduced.
- [ ] Realistic content was used where available.
- [ ] Long, empty, loading, error, and disabled states were considered.
- [ ] Mobile and desktop layouts were checked.
- [ ] Interactive states are intentional: hover, focus, pressed, disabled, pending.
- [ ] No dead controls or decorative interactions remain.
- [ ] No placeholder copy remains unintentionally.
- [ ] Visual comparison was performed against supplied references or neighboring screens when applicable.
