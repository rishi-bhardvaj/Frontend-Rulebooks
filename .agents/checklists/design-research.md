# Design Research Checklist

- [ ] Existing product/design system/brand assets inspected.
- [ ] Actual design or UX problem identified.
- [ ] Multiple relevant references studied when practical.
- [ ] Reference observations separated from assumptions.
- [ ] Visual thesis written before substantial implementation.
- [ ] Inspiration adapted rather than cloned.
- [ ] Real content/data used for the review.
- [ ] Responsive behavior checked at representative sizes.
- [ ] Keyboard/focus/contrast/semantics checked.
- [ ] Reduced-motion behavior considered.
- [ ] Loading, empty, error, disabled, and success states considered.
- [ ] Decorative effects have a product reason.
- [ ] No generic AI-template patterns remain without justification.
- [ ] Verification evidence recorded.
