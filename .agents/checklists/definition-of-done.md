# Definition of Done

- [ ] Requirements and affected flows were inspected.
- [ ] Existing architecture and design system were reused.
- [ ] Real API/data contracts were checked where applicable.
- [ ] Authentication/permission behavior is correct.
- [ ] Loading/empty/error/success states are handled.
- [ ] Forms and validation are handled.
- [ ] Keyboard/accessibility requirements were checked.
- [ ] Responsive behavior was checked.
- [ ] Real browser flow was exercised when possible.
- [ ] Relevant tests were actually run.
- [ ] Mocks/placeholders/fake data are not left in production paths.
- [ ] No secrets were hardcoded or exposed.
- [ ] Exact configuration requirements were documented.
- [ ] Build/lint/typecheck results are recorded honestly.
- [ ] Remaining risks and blockers are reported.
