# Accessibility Checklist

- [ ] Semantic HTML used where appropriate.
- [ ] Every control has an accessible name.
- [ ] Keyboard navigation works.
- [ ] Focus order and visible focus are correct.
- [ ] Form errors are associated and discoverable.
- [ ] Dialog/menu focus behavior is correct.
- [ ] Color is not the sole information channel.
- [ ] Reduced motion is respected where applicable.
- [ ] Images have appropriate alternative treatment.
- [ ] Representative responsive/reflow behavior was checked.
- [ ] Automated accessibility checks were run when available.
