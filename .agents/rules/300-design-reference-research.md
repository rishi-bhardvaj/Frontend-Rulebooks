# Design Reference Research Workflow

**Severity: HIGH**  
**Activation:** Model Decision for material visual work.

When a user asks for a design inspired by contemporary sites, do not generate a visual style from memory alone.

## Research questions

Identify which problem requires inspiration:

- brand identity and visual language
- landing-page composition
- product/application UX
- information-dense dashboards
- editorial/content presentation
- motion and interaction
- typography
- image/art direction
- conversion and CTA hierarchy

Use an appropriate mix of sources. For current web inspiration, Awwwards, Brandfetch, Godly/Recent, SiteInspire, CSS Design Awards, Mobbin, Page Flows, Behance, Dribbble, Land-book, Lapa Ninja, One Page Love, and The FWA can serve as research inputs. Prefer real production interfaces for usability decisions and curated award galleries for craft/experimentation.

## Evidence discipline

A reference can demonstrate that a pattern exists; it does not prove that the pattern is appropriate for this product.

For each material decision, ask:

1. What was observed?
2. Why might it work?
3. What product requirement does it solve here?
4. What accessibility, performance, responsive, content, and implementation tradeoffs does it create?
5. What was changed rather than copied?
6. How will the result be verified?

Do not claim to have inspected a reference that was not actually accessible. Separate direct observation from general inspiration or inference.

## Brand-aware design

Brandfetch and similar brand-data sources can be used to understand how brands express logos, colors, typography, assets, and identity. Treat those observations as brand-system research. Do not scrape or reproduce proprietary assets without the appropriate rights.

When the product has an established brand, preserve its identity unless the user explicitly asks for a rebrand. When no brand system exists, create a restrained visual thesis from the product's domain, audience, content, and researched references rather than defaulting to a fashionable AI aesthetic.

## Output

For material design work, add a short design research note to the task or implementation report:

**Visual direction:** one paragraph.

**Reference set:** at least three sources when practical.

**Borrowed principles:** the small number of visual/interaction principles adopted.

**Deliberate differences:** what was intentionally not copied and why.

**Verification:** viewport sizes, interaction states, accessibility checks, and visual review performed.
